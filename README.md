# Rafeeq (رفيق)

Quest & leveling companion for **WoW: Forever**: a smart quest tracker, nearby-quest suggestions, a guide arrow, map and minimap pins, an auto macro maker and auto vendor. Available in English or Arabic.

- Addon: [`Rafeeq/`](Rafeeq/), with its user guide in [`Rafeeq/README.md`](Rafeeq/README.md)
- Tests: `pip install lupa && git clone --depth 1 https://github.com/Questie/QuestieDB.git ../QuestieDB && python3 tests/run.py --qdb ../QuestieDB`
- Release: `python3 scripts/bump.py X.Y.Z "change"`, then commit, tag `vX.Y.Z` and push. GitHub Actions uploads the release to CurseForge.
